# Task brief (template)

Claude's Help Center says results improve when a request names the outcome, the format and the inputs. This template covers those three plus limits.

```
Outcome: <what I want to end up with, e.g. a one-page summary>
Format: <Word doc / spreadsheet with a tab per region / 10-slide deck / Slack-ready message>
Inputs: <files, folders, links or connected apps to work from>
Limits: <what not to touch, what to ask about first>
Done when: <how I will check it>
```

Example:

```
Outcome: a comparison of five project management tools for a 6-person team.
Format: a spreadsheet, one row per tool, plus a half-page summary doc.
Inputs: web research; our current process notes in ./inputs/process.md.
Limits: do not sign up for any trials.
Done when: each row has a source link and the summary names one pick.
```
