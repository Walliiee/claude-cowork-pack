# Folder instructions (template)

In Claude Desktop, folder instructions live in the Customize panel and load whenever you pick that folder for a task. Claude can also update them during a session. Use one per working folder.

```
This folder: <what it holds, e.g. monthly reporting for the sales team>.

Inputs live in: ./inputs   (do not edit these)
Put finished work in: ./output, named YYYY-MM-DD-<topic>.<ext>
Drafts and scratch files: ./scratch, safe to overwrite

House style: <short rules, or "see ./style.md">
Never: delete files in ./inputs, send anything outside this folder without asking.
```
