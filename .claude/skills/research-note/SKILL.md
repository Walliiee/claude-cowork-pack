# Research note

1. Restate the question in one line. If it is ambiguous, ask before researching.
2. Use several independent sources. Prefer primary sources such as official docs, filings, and original announcements over summaries.
3. Cross-check the key claims. If two good sources disagree, say so instead of picking one.
4. Write the note:
   - Date and question at the top.
   - A two-line **TL;DR**.
   - Findings as short points, each with its source linked.
   - **So what**: the one decision or action this should inform.
5. List what you could not verify.
