# Compare tools

1. Restate the requirements as a short list: must-haves first, then nice-to-haves. If team size, budget or required integrations are missing, ask.
2. Search the web for candidates. Prefer the vendor's own pages for features and prices, and independent reviews for everything else.
3. Build a spreadsheet: one row per tool, one column per requirement, plus price, source link and date checked.
4. Mark each cell yes, no or unclear. Use unclear when the source does not say.
5. Write a one-page summary: the shortlist, the main trade-offs, and one recommendation with the reason.
6. List what you could not verify.

## Rules

- Every fact in the sheet has a source link.
- Do not sign up for trials or contact vendors.
